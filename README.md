# Каскад (Cascade)

Paper-плагин для Minecraft 26.3: режим «три в ряд» на вертикальной стене руды.

Перед игроком на личном участке стоит стена руды 7×9. Удар выбивает блок, всё, что выше, падает вниз
(анимация через `BlockDisplay`). Три одинаковых блока в ряд лопаются, а сразу за ними может пойти
целая цепочка с растущим множителем.

## Возможности

- **Каскады и спецблоки:** TNT за 4 в ряд, магма-бомба за фигуры «Г» и «Т», аметист за 5 в ряд.
- **НПС-жители:** Скупщик, Кузнец, Мудрец и Проводник, у каждого своё меню.
- **5 шахт** со своей обстановкой и правилами: сундуки-бочки, лёд, обсидиан, гравитация вверх.
- **Древо навыков на 228 узлов:** 6 веток по 38 навыков. Всё древо описано в `src/main/resources/tree.txt`.
- **Своя графика в инвентаре:** круглая карта древа и страницы веток нарисованы символами
  шрифта ресурспака. Ресурспак плагин раздаёт игрокам сам.
- Рекорды каскадов (`/top`), сохранение прогресса игроков.

## Команды

| Команда | Что делает |
|---|---|
| `/menu` (`/cs`) | меню улучшений |
| `/skills` (`/навыки`) | древо навыков |
| `/mines` | выбор шахты |
| `/sell` | продать рюкзак |
| `/wall` | вернуться к своей стене |
| `/top` | рекорды каскадов |
| `/cadmin xp\|coins\|skills\|mines\|reset` | админ-команды для тестов (только оператор) |

## Сборка и запуск

Нужна JDK 25+.

```
gradlew.bat runServer
```

Paper 26.3 скачается сам и запустится на `localhost:25565`. Готовый плагин лежит в
`build/libs/cascade-<версия>.jar`.

### Графика древа

Иконки узлов (`textures/tree/ic_*.png`) и страницы веток (`textures/gui/branch*.png`) собраны
из текстур Minecraft, поэтому в репозитории их нет. Чтобы сгенерировать их из своего клиента:

```
java tools/GenArt.java src/main/pack src/main/resources/tree.txt <путь к client.jar Minecraft 26.3> src/main/resources/tree_glyphs.txt
```

## Где что

- `Wall.java`: стена, падение блоков, поиск рядов и цепочек.
- `Balance.java`: все цифры баланса.
- `Skills.java`, `SkillMenu.java`: древо навыков и его меню.
- `Mine.java`, `MineMenu.java`: шахты и их правила.
- `Npcs.java`: жители.
- `PackServer.java`: раздача ресурспака игрокам.
- `Store.java`, `PlayerData.java`: сохранение игроков.
